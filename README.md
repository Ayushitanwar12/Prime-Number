
/**
 * PrefixSum.java
 * 
 * This program demonstrates how to compute the Prefix Sum of a 1D array.
 * 
 * A prefix sum array is used to quickly compute the sum of elements
 * in a given range [0, i] for all i.
 * 
 * For example, given an array [1, 2, 3, 4],
 * the prefix sum array will be [1, 3, 6, 10].
 * 
 * This technique is useful in many problems involving range queries,
 * cumulative sums, and dynamic programming.
 */
